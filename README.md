# box.agent releases

Prebuilt binaries for `box-agent`. This repository only hosts release artifacts; the source is not public.

Download the binary for your platform from the [latest release](https://github.com/LLMOcean/box.agent-releases/releases/latest):

| Platform | Asset |
|---|---|
| Linux x86_64 | `box-agent-linux-amd64` |
| Linux arm64 | `box-agent-linux-arm64` |
| macOS Intel | `box-agent-darwin-amd64` |
| macOS Apple Silicon | `box-agent-darwin-arm64` |
| Windows x86_64 | `box-agent-windows-amd64.exe` |

Each release also includes a `SHA256SUMS` file.
